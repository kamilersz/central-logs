# Build dependencies for Read the Docs.
#
# INTENTIONALLY EMPTY.
#
# The mkdocs build for this site is intentionally dependency-free:
# the mkdocs.yml uses the bundled `mkdocs` theme and only Python-Markdown
# extensions that ship with mkdocs core (no pymdownx, no pygments, no
# mkdocs-material). RTD's pre-installed mkdocs environment provides
# everything the build needs.
#
# When this file is present, RTD's mkdocs builder runs
# `pip install -r requirements.txt` BEFORE `mkdocs build`. Leaving it
# empty keeps that step a no-op — the build cannot fail on a missing
# optional dependency, and the version of mkdocs RTD ships with is
# the only one in the env.
#
# If you ever want to add mkdocs-material / pymdownx etc., add them
# here AND be aware that:
#   1. RTD's mkdocs builder may or may not run this install step
#      depending on the workflow it picks (it has changed over time);
#   2. Material's pymdownx chain pulls in pygments at runtime, so
#      pygments needs to be pinned here too;
#   3. RTD pins transitive versions, so mismatches can cause silent
#   breakage months later.
